# auto-hdp

CLI-парсер заданий с `horodigital.ru`. Авторизуется по логину и паролю,
выбирает предмет и модуль, затем сохраняет задания в HTML, JSON и полноразмерных
PNG-скриншотах. В тестах проходит по доступным вопросам без выбора и отправки
ответов. По умолчанию обрабатывает только невыполненные задания уровней 1/2/3,
которые не находятся на проверке.

## Установка

Требуется Python 3.11+.

```bash
git clone https://github.com/MIkleRustRepin/auto-hdp.git
cd auto-hdp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
playwright install chromium
cp .env.example .env
```

Укажите данные для входа в `.env`:

```dotenv
HDP_LOGIN=ваш_логин
HDP_PASSWORD=ваш_пароль
```

Если Chromium от Playwright не установлен, парсер попробует использовать
системный Google Chrome или Chromium.

## Использование

Скачать последний доступный модуль предмета:

```bash
auto-hdp --subject "Биология"
```

Скачать конкретный модуль по названию:

```bash
auto-hdp \
  --subject "Математика" \
  --module "Г1. Введение в стереометрию"
```

Снять вообще все задания, включая выполненные, проверяемые и уровень 4:

```bash
auto-hdp --subject "Биология" --all-tasks
```

## Решение через Codex

Проект использует официальный Python SDK `openai-codex`, который устанавливается
вместе с `pip install -e .`. SDK запускает закреплённую версию локального Codex
app-server, а не вызывает `codex exec` через subprocess.

Один раз подключите аккаунт ChatGPT:

```bash
codex login
```

Также Codex может использовать API-ключ:

```bash
printenv OPENAI_API_KEY | codex login --with-api-key
```

После этого добавьте `--solve-with-codex` (короткий вариант — `--codex`):

```bash
auto-hdp \
  --subject "Математика" \
  --module "Г1. Введение в стереометрию" \
  --solve-with-codex
```

Парсер отправит Codex полноразмерный скриншот задания, а для теста — отдельные
скриншоты доступных вопросов. По умолчанию используется `gpt-5.6-terra` с
reasoning effort `low`. Промпт просит решить задание и вернуть только чистый
текст без Markdown и декоративных выделений, если оформление прямо не требуется
условием. Итоговый ответ сохраняется в `solution.txt` внутри каталога задания.

Можно изменить промпт, модель и reasoning effort:

```bash
auto-hdp --subject "Биология" --codex \
  --codex-prompt "Реши подробно и дай готовый ответ на русском" \
  --codex-model gpt-5.6-terra \
  --codex-effort low
```

Каждый SDK-thread запускается из временного пустого каталога, в read-only и
ephemeral-режиме. Codex не вводит и не отправляет ответы на учебную платформу.
Временная перегрузка модели автоматически повторяется до пяти раз.

Если процесс остановился или компьютер перезагрузился, продолжите тот же каталог:

```bash
auto-hdp \
  --subject "Математика" \
  --module "Г1. Введение в стереометрию" \
  --codex \
  --resume "output/Математика/<каталог-запуска>"
```

Готовые `solution.txt` будут пропущены. Для незавершённых заданий повторно
используются уже снятые PNG; отсутствующие задания снимаются и решаются дальше.

Предмет и модуль также можно указывать по их ID/UUID. Без аргументов команда
покажет доступные предметы:

```bash
auto-hdp
```

Результаты сохраняются в `output/<предмет>/<дата>-<модуль>/`. Итог и состояние
каждого задания записываются в `manifest.json`.

Авторизация кэшируется в `.auth/storage-state.json`. Пока сессия действует,
повторный вход не выполняется; при `401/403` парсер автоматически авторизуется
заново и повторяет запрос.

> Открытие задания отмечает его просмотренным. Вход в тест может создать
> незавершённую попытку и запустить таймер. Парсер не выбирает ответы и не
> отправляет тест. При `--codex` скриншоты заданий передаются в OpenAI и расходуют
> лимиты выбранного способа авторизации.

## Проверка

```bash
python -m unittest discover -s tests -v
```

HAR-файлы, `.env`, auth-кэш и результаты парсинга исключены из Git, поскольку
могут содержать персональные данные и cookie.
