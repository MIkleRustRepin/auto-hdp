# auto-hdp

CLI-парсер заданий с `horodigital.ru`. Авторизуется по логину и паролю,
выбирает предмет и модуль, затем сохраняет задания в HTML, JSON и полноразмерных
PNG-скриншотах. В тестах проходит по доступным вопросам без выбора и отправки
ответов.

## Установка

Требуется Python 3.11+.

```bash
git clone https://github.com/MIkleRustRepin/auto-hdp.git
cd auto-hdp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
playwright install chromium
cp .env.example .env
```

Укажите данные для входа в `.env`:

```dotenv
HDP_LOGIN=ваш_логин
HDP_PASSWORD=ваш_пароль
```

Если Chromium от Playwright не установлен, парсер попробует использовать
системный Google Chrome или Chromium.

## Использование

Скачать последний доступный модуль предмета:

```bash
auto-hdp --subject "Биология"
```

Скачать конкретный модуль по названию:

```bash
auto-hdp \
  --subject "Математика" \
  --module "Г1. Введение в стереометрию"
```

Предмет и модуль также можно указывать по их ID/UUID. Без аргументов команда
покажет доступные предметы:

```bash
auto-hdp
```

Результаты сохраняются в `output/<предмет>/<дата>-<модуль>/`. Итог и состояние
каждого задания записываются в `manifest.json`.

Авторизация кэшируется в `.auth/storage-state.json`. Пока сессия действует,
повторный вход не выполняется; при `401/403` парсер автоматически авторизуется
заново и повторяет запрос.

> Открытие задания отмечает его просмотренным. Вход в тест может создать
> незавершённую попытку и запустить таймер. Парсер не выбирает ответы и не
> отправляет тест.

## Проверка

```bash
python -m unittest discover -s tests -v
```

HAR-файлы, `.env`, auth-кэш и результаты парсинга исключены из Git, поскольку
могут содержать персональные данные и cookie.
